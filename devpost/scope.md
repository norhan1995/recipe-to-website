# Recipe to Website
A guided coding workspace for beginners making a personal web page.

## The Unique Kernel
Every small recipe pairs editable code with the resulting page, so the beginner can connect a code change with what appears on screen.

## Who It's For
A beginner who can copy snippets but wants to understand how HTML, CSS, and JavaScript fit together.

## The Core Loop
Read a short recipe, edit its code, run it, inspect the live result, then move to the next recipe. Download the completed personal page.

## Inspiration & Identity
The learner selected “Recipe to Website”, “Build a personal page”, “Guided code editing”, and “Modern and classy”. These are confirmed choices. The original goal is to finish a new project and enter Build With AI: Basics.

## What "Working" Looks Like
Changing a heading changes the visible personal page; editing a CSS color changes the appearance; JavaScript makes a button respond; the exported HTML opens independently.

## The POC Boundary
One personal-page recipe with HTML, CSS, and JavaScript steps, explanations, live preview, and download. Exact step text, layout details, and implementation are proposed below for review.

## Explicitly Cut
Accounts, payments, arbitrary project generation, AI runtime calls, and multi-user editing: none is needed to demonstrate the recipe loop.

## Open Review
The learner approved the proposed experience and build order on October 5, 2026: “Yes the plan looks good”.
